# 计算参数更新检查（2026-09-08）

范围：Settings、Solution Generator、站点因子、设备 Profiles、报价、物理计算、电价回放和年度财务比较的主要 UI/API 路径。检查保存值、生成的计算输入、缓存恢复及计算期间的输入变更。Python 继续负责计算；本次没有引入设备老化或新效率模型。

## 确认并修复的问题

| 问题 | 修复后行为 |
| --- | --- |
| 报价快照更新时，前端把旧自动报价当作手工输入保留 | 单独记录手工报价标记；新价格快照更新自动报价，保留手工覆盖及跨页面草稿 |
| 保存站点因子后，旧方案仍可从其他计算入口运行 | 后端比较保存因子与方案快照；不一致时返回 409，要求重新生成方案；已保存的物理/电价结果显示过期 |
| 修改已选设备的有效性能参数后，旧方案仍沿用原设备快照 | 检查已选 Profile 的有效字段及发布状态；参数变化或设备被撤回后，需要重新生成；不把新值悄悄写入旧计算 |
| 手工报价模式的财务请求缺少 Settings 并发变更保护 | UI 提交读取到的 Settings 摘要，后端在计算前及写入前核对；发现变更则拒绝保存混用参数的结果 |
| 资料字段可以编辑，但页面未说明其不参与计算 | 在 Profile 编辑器和目录报价中标明 Reference only；补充 PV 时序模式的条件说明 |

站点因子保存和 Settings 保存也会刷新相关查询，避免页面继续显示旧缓存。计算结果写入时再次检查方案输入，覆盖分析正在运行时修改设置的情况。

## 生效方式和模型边界

| 参数 | 当前用途 / 更新方式 |
| --- | --- |
| Discount rate、Analysis term、Value escalation、Value degradation、Annual O&M | 参与年度现金流或财务指标。Settings 保存后的新默认值在下一次财务分析中生效；此前的默认值同步修复保留 |
| 年发电量、遮挡、积灰、温度损失、线损、其他损失、系统可用率 | 进入方案的年比发电量或综合降额。保存后重新生成方案并重新分析 |
| 经纬度、倾角、方位角 | 几何时序模式下影响间隔发电分布；Legacy generic 模式不使用这些量。年发电量仍由所填资源值和损失确定；需要 PVGIS 更新时显式刷新并应用 |
| PV / 电池容量范围、DC/AC 比、连接结构、并网限制、SOC、充放电及无功限制 | 生成方案和调度输入。修改生成器草稿不会自行重写已保存方案，必须 Generate solutions |
| 电池单元容量/功率、RTE、DoD | 进入功率、效率或可用能量计算。修改已选 Profile 后重新生成 |
| 电池转换效率 | 仅 Pack RTE + converter losses 模式叠加转换损失；Whole-system AC RTE 模式已包含转换损失，不能再次叠加 |
| 逆变器有功、视在功率、无功开关及上限 | 用于方案定容和有功/无功能力约束；修改已选 Profile 后重新生成。关闭无功支持时，无功上限不产生补偿效果 |
| 设备资本价格曲线、安装杂项、STC 设置 | Python 报价快照使用当前有效输入。过期快照需要重新生成；GET 只恢复已保存快照。手工 Net CAPEX 作为明确报价保留，不重复扣补贴 |
| 电价、时段、需量、损耗因子及计费口径 | 从已批准的电价配置参与回放；变更导致旧结果失效。本次未发现类似的参数同步遗漏；未批准的客户金额计算仍被拦截 |

改变有效参数不保证每个输出数值都变化：例如未触及的功率上限、不适用时段的费率或非约束条件，可能对某个方案结果没有影响。

## 当前只记录、不进入主比较计算的字段

- 光伏：单板额定功率、组件效率、温度系数、设备年度衰减、组件技术类型。当前采用连续 kWp 定容，温度影响使用站点温度损失；不按单板数量或温度系数重新建模。
- 电池：待机损耗、年度容量衰减、最小/最大单元数、化学类型。单元数可做字段合法性校验，但不限制连续容量搜索。
- 逆变器：欧洲效率、最大效率、超前/滞后功率因数限制、P–Q 曲线可用标记、零有功无功能力和夜间无功能力。当前采用既有的圆形 P/Q 能力约束，不使用这些资料字段。
- 目录设备的 replacement cost 和绝对 Annual O&M：主年度比较的替换事件为空，实际年度 O&M 使用 Net CAPEX × Finance Annual O&M 比例。旧的独立财务接口另有目录 O&M/替换事件支持，不能与主比较混淆。

Finance 的 Value degradation 会降低未来年度价值，但不等价于逐年仿真光伏衰减、电池老化或更换。
